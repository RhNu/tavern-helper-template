# 后端插件开发

本模板除浏览器端的前端界面/脚本外, 也支持开发 SillyTavern 服务端插件, 用于持有密钥调用外部 API 或注册 HTTP 端点。

## 目录约定

- 源码: `src/plugins/<插件名>/index.ts`, 每个子目录一个插件
- 产物: `dist/plugins/<插件名>/index.cjs`, 随仓库提交, 但不会上传到 CDN/R2
- 插件类型定义: `src/plugins/@types/sillytavern-plugin.d.ts`
- Node 环境类型检查: `tsconfig.plugins.json`

## 构建与检查

```bash
pnpm build:plugins          # 生产构建 (压缩)
pnpm build:dev -- --kind=plugins # 开发构建 (不压缩)
pnpm watch:plugins          # 监听并自动重建
pnpm typecheck:plugins      # TypeScript 类型检查
```

`tools/build.ts` 使用 tsdown 将每个插件打成 Node 18
CommonJS 单文件。第三方依赖会打进产物，Node 内置模块和可选的 `canvas`
依赖保持外部引用；若引入其他原生/可选依赖，请按实际部署环境调整构建脚本。

## 插件形态

- 插件目录复制到 SillyTavern 根目录的 `plugins/` 下，并在 `config.yaml` 中启用 `enableServerPlugins: true`。
- 入口产物使用 `.cjs`，以兼容 SillyTavern 的 ESM 根环境。
- 模块导出 `info`、`init(router)`，可选导出 `exit()`；路由挂载在 `/api/plugins/{id}/` 下。
- 插件运行在酒馆 Node 进程中，未沙箱化，只应安装可信来源的插件。

前端请求插件端点时，应按酒馆接口要求携带 `SillyTavern.getRequestHeaders()`。
